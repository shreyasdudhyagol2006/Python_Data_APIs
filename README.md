
# Python Data & APIs Project

## Project Overview
This project performs data analysis, data cleaning,
data visualization and REST API integration using Python.

## Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Requests
- REST API
- JSON

## Project Features
1. Load CSV datasets.
2. Handle missing values.
3. Remove duplicate records.
4. Perform numerical calculations.
5. Analyse product-wise sales.
6. Create product-wise revenue charts.
7. Create city-wise revenue charts.
8. Fetch data from REST APIs.
9. Process JSON responses.
10. Generate automatic reports.

## Project Structure
Python_Data_APIs/
    data/
        sales.csv
    src/
        __init__.py
        main.py
        data_analysis.py
        api_data.py
    reports/
    requirements.txt
    README.md

## How to Run

Install dependencies:
pip install -r requirements.txt

Run the project:
python src/main.py

## Output
- Cleaned sales dataset
- API data CSV
- Product-wise chart
- City-wise chart
- Analysis report
